# 게임기획 스튜디오 제품 준비 기준

## 현재 판정

현재 빌드는 개인 실사용과 비공개 베타에 투입할 수 있는 **기능 완성 기반**입니다. 작업공간 저장, 등록된 다섯 도구의 동일 창 실행, 기획서 편집·Office 출력, 선택형 AI, 도구 간 자료 참조까지 하나의 제품 흐름으로 연결되어 있습니다.

다만 “판매 가능”은 기능 수가 아니라 설치·복구·보안·법적 고지·사용자 검증까지 통과했다는 뜻입니다. 아래 출하 게이트를 모두 통과하기 전에는 정식 판매판으로 부르지 않습니다.

## 이미 충족한 기반

- localhost나 사용자의 별도 서버 실행 없이 C++/WebView2 셸에서 동작
- X 버튼 트레이 동작과 작업공간·탭 복원
- revision 충돌 감지, 원자적 저장, 최근 20개 백업
- API 없는 기본 작성·편집·PPTX·Word 출력
- Windows 자격 증명 관리자 기반 OpenRouter 키 보관
- 호출 전 예상 비용 제한과 호출 후 실제 비용 기록
- AI 제안의 근거 ID·수치 검증과 명시적 적용
- 테이블·패턴 자료의 명시적 연결과 편집 가능한 PPT 벡터 변환
- Office ZIP/XML/16:9/라이브 텍스트 사전검사
- 1500×920, 1100×720 임베드 UI 자동 조작과 오버플로 검사

## 정식 판매 전 출하 게이트

### 6. 설치·업데이트·복구

- 서명된 MSIX 또는 설치 프로그램, 깨끗한 Windows 환경 설치/삭제 검사
- WebView2 Runtime 부재·구버전 처리
- 데이터 내보내기, 백업 복원, 버전별 마이그레이션과 롤백
- 자체 업데이트 채널과 업데이트 실패 복구. Oh My PPT 상류 업데이트 채널에는 연결하지 않음

### 7. 품질·보안·법적 준비

- 최소 20개 실제 게임 기획 덱과 5개 이상의 장기 작업공간으로 베타 테스트
- 125/150/200% DPI, 작은 화면, 키보드 전용 조작과 접근성 검사
- 비밀정보 로그·덤프 유출, WebView 메시지 위조, 경로 조작, 악성 프로젝트 파일 보안 검사
- DevToys, Oh My PPT와 모든 런타임 의존성의 라이선스·NOTICE 최종 감사
- 개인정보 처리방침, 이용약관, 지원 범위와 OpenRouter 비용 책임 고지

### 8. 제품 차별화 완성

- 사용자가 승인한 레이아웃 선택을 축적하는 개인 디자인 메모리
- 같은 내용으로 복수 아트 디렉션을 비교하는 시각 회귀 평가 세트
- Unity/Unreal 내보내기와 테이블·패턴 변경 영향의 양방향 추적
- 실패율, 완료 시간, 수동 수정량을 측정하는 로컬 옵트인 품질 지표
- 샘플 프로젝트, 처음 사용 안내와 제품 내 복구 가능한 튜토리얼

## 출하 판정 규칙

정식 판매 후보는 다음을 동시에 만족해야 합니다.

1. 차단 등급 버그가 0건이고 주요 사용자 흐름 자동검사가 모두 통과합니다.
2. 새 PC 설치부터 첫 PPTX·Word 생성까지 사용자가 개발자 도움 없이 완료합니다.
3. 프로그램 강제 종료와 저장 충돌 뒤에도 최신 데이터 또는 백업으로 복구됩니다.
4. 실제 기획자 베타에서 기존 수작업보다 초안부터 제출본까지 걸리는 시간이 유의미하게 줄어듭니다.
5. 제3자 코드와 AI 비용에 관한 고지가 제품 안과 배포물에 함께 존재합니다.

“혁신”은 기능 설명이 아니라 4번의 실측 결과로 판단합니다.
