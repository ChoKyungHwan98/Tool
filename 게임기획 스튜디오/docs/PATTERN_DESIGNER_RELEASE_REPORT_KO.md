# 패턴 디자이너 v1 완료 보고서

## 제품 정의

패턴 디자이너는 FSM과 HFSM을 서로 다른 문서 형식으로 나누지 않고, 하나의 **상태 머신 문서** 안에서 하위 상태 머신을 중첩해 설계하는 게임 AI 저작 도구다. 행동 트리는 실행 의미가 다르므로 별도 그래프 형식으로 유지한다.

## 0–8단계 완료 범위

0. 통합 모델과 마이그레이션: Pattern IR v2, 기존 FSM/HFSM 자료 자동 변환, 원본 백업과 복구 저널
1. 편집기 작업 흐름: 그래프 문서 목록, 계층 탐색, 다중 상태 머신, 복제·이름 변경·안전 삭제
2. HFSM 의미론: Entry·Exit·Any State, 하위 스코프, 기본 상태, 히스토리, 병렬 영역, 스코프 경계 검증
3. 저작 데이터: 블랙보드, 재사용 행동·조건 카탈로그, Enter·Update·Exit·Can Exit 바인딩
4. 실행과 디버깅: XState·Mistreevous 실행기, 단계 실행, 이벤트 주입, 중단점, 커버리지, 실패 조건, 결정적 재생
5. Unity 어댑터: UPM 구조, ScriptedImporter, 런타임·에디터 코드, 테스트·샘플·문서가 포함된 ZIP 생성
6. Unreal 어댑터: 플러그인 구조, Runtime·Editor 모듈, DataAsset·ActorComponent·Factory·테스트가 포함된 ZIP 생성
7. 제품 안정화: 스키마 검증, 진단 보고서, ID 안전 복제, 저장 복구, 코드 분할, 한국어 UI와 단축키
8. 통합 검증: 게임기획 스튜디오 내 임베드, 포터블 EXE 빌드, 1500·1100·760·540px 작업 시나리오 검증

## 검증 결과

- 패턴 디자이너: TypeScript 타입 검사 통과
- ESLint 통과
- 단위·통합 테스트 11개 파일, 30개 테스트 통과
- 게임기획 스튜디오 UI 테스트 4개 통과
- 네이티브 ProjectStore 영속성 테스트 통과
- 1500×920, 1100×760, 760×720, 540×720에서 임베드·그래프 전환·하위 머신·시뮬레이션·속성 편집·단축키·오버플로 시나리오 통과
- 패턴 초기 진입 JavaScript는 약 109KB이며 그래프 편집기·시뮬레이션·엔진 패키지 생성을 지연 로딩한다.

## 포트폴리오에서 주장할 수 있는 것

- Unity Animator와 유사한 단일 상태 머신 저작 흐름에 HFSM 계층을 결합했다.
- 단순 노드 캔버스가 아니라 검증·실행·디버깅·엔진 패키징까지 이어지는 도구 체계를 설계했다.
- 기존 FSM/HFSM 데이터를 잃지 않는 마이그레이션과 복구 전략을 구현했다.
- 데스크톱부터 좁은 화면까지 동일 기능을 유지하는 편집 UX를 검증했다.

## 아직 주장하면 안 되는 것

Unity UPM과 Unreal 플러그인은 설치 가능한 **소스 패키지 생성과 구조 테스트**까지 완료했다. 실제 Unity/Unreal 프로젝트에서의 컴파일·에디터 임포트·플레이 모드 실행 검증은 별도 단계다. 해당 검증 전에는 “엔진 완전 연동 완료”가 아니라 “엔진 어댑터 패키지 생성 완료”라고 표현한다.
