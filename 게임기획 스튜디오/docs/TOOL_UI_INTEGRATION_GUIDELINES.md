# 도구 UI·탐색·홈 화면 통합 지침

이 문서는 게임 기획 스튜디오에 들어가는 모든 도구가 따라야 하는 필수 계약이다. 새 도구를 만들거나 이식하기 전에 전체를 읽고, 완료 후 `tool-guideline-ack.json`에 도구 ID를 등록한다. 빌드 검사가 미등록 도구를 거부한다.

## 1. 스튜디오와 도구의 탐색 소유권

- 스튜디오 상단의 뒤로가기는 도구를 즉시 닫는 버튼이 아니다.
- 도구 내부에 이전 단계가 있으면 `game-design-studio:tool-navigation` 메시지의 `navigate-back`을 먼저 처리한다.
- 도구는 처리 결과를 같은 채널의 `navigate-back:result`로 응답한다.
- 내부 최상위 화면에서만 `handled: false`를 반환하며, 그때 스튜디오가 도구 보관함으로 이동한다.
- 도구 안에 스튜디오 뒤로가기와 중복되는 전역 뒤로가기 버튼을 추가하지 않는다.
- 저장 상태 문구처럼 사용자의 다음 행동에 도움이 되지 않는 상시 문구는 표시하지 않는다.

## 2. 임베디드 작업 표면

- 스튜디오 작업 표면은 데스크톱에서 `16px`, 좁은 화면에서 `12px` 모서리를 사용한다.
- iframe과 도구 루트는 부모 표면을 가득 채우며 모서리 클리핑을 깨지 않는다.
- 로딩 화면과 실제 화면의 모서리·배경이 서로 바뀌어 보이면 안 된다.
- 도구가 자체 헤더를 갖더라도 스튜디오 제목 표시줄이나 전역 탐색을 복제하지 않는다.
- 도구의 최상위 루트는 `height: 100%`, `min-height: 0`, `overflow: hidden`을 기본으로 한다.

## 3. 프로젝트 진입 흐름

- 최초 설정이나 모드 선택은 프로젝트 생성 후 한 번만 보여 준다.
- 선택 결과는 프로젝트 ID 기준으로 저장한다.
- 다시 프로젝트를 열면 마지막 작업 화면으로 직접 진입한다.
- 내부 뒤로가기로 프로젝트 목록에 돌아갈 수 있어야 하며, 이 동작이 도구 종료와 같아서는 안 된다.

## 4. 프로젝트 홈 화면 배열·삭제·폴더

- 프로젝트 카드는 공용 프로젝트 홈 런처에 나타나야 한다.
- 프로젝트를 우클릭하면 삭제 메뉴를 표시한다. 삭제 전에는 프로젝트 이름과 복구 위치를 설명하는 확인 단계를 둔다.
- 삭제는 영구 제거 대신 프로젝트와 같은 상위 경로의 `.게임기획 스튜디오 휴지통`으로 폴더를 이동한다.
- 프로젝트를 480ms 동안 좌클릭해 누르면 편집 모드에 진입한다.
- 길게 누른 포인터는 끊기지 않고 바로 드래그로 이어져야 한다.
- 카드 중앙에 놓으면 두 프로젝트를 홈 화면 폴더로 합친다.
- 카드 가장자리에 놓으면 폴더를 만들지 않고 순서만 바꾼다.
- 폴더 이름은 사용자가 수정할 수 있어야 한다.
- 폴더에서 프로젝트를 다시 꺼낼 수 있어야 한다.
- 배열과 폴더는 로컬에 영속화하고, 새 프로젝트는 기존 사용자 배열 끝에 자동 추가한다.
- 삭제된 프로젝트는 저장된 배열과 폴더에서도 자동 정리한다.
- 검색은 개인 배열을 파괴하지 않고 표시 결과만 좁힌다.

## 5. 제스처와 모션

- 포인터를 누른 순간 시각 피드백을 제공한다.
- 드래그는 포인터를 1:1로 추적하고 Pointer Capture를 사용한다.
- 이동 임계값은 8px로 두어 스크롤과 드래그를 구분한다.
- 반복적인 키보드 이동은 애니메이션하지 않는다.
- 드래그·드롭 피드백은 `transform`과 `opacity`만 사용한다.
- `prefers-reduced-motion`과 `prefers-reduced-transparency` 대체 표현을 제공한다.
- 입력을 애니메이션이 끝날 때까지 잠그지 않는다.

## 6. 새 도구 완료 체크리스트

- [ ] **`SHARED_PRODUCT_UI_GUIDELINE.md` 「⚠ 홈 레이아웃은 모든 도구가 똑같다」를 읽고, 기준 화면(AI 리뷰데이터 분석 홈)과 같은 크기로 나란히 띄워 뼈대가 같은지 스크린샷으로 비교했다.**
- [ ] 공용 `ToolDefinition`에 고유 ID, 이름, 설명, 분류, 검색어, 입출력을 등록했다.
- [ ] 공용 프로젝트 홈에서 새 도구가 만든 프로젝트가 검색·배열·폴더·휴지통 규칙을 깨지 않는다.
- [ ] **마우스 사이드 버튼과 스튜디오 `←`가 도구 안에서 한 칸씩 동작하고, 끝에서 스튜디오로 넘어간다** (`SHARED_PRODUCT_UI_GUIDELINE.md` 「⚠ 스튜디오와 도구 사이의 뒤로가기 계약」). 스튜디오 안에서는 도구 자체 홈·뒤로 버튼을 숨긴다.
- [ ] 스튜디오 프레임의 16px/12px 모서리를 유지한다.
- [ ] 글꼴·크기·굵기가 `SHARED_PRODUCT_UI_GUIDELINE.md` 「글자 기준 — 모든 화면」을 따른다 (빌드 검사 통과, 클래스 없는 `small`도 12px 이상).
- [ ] 도구 빌드 결과를 `scripts/build.ps1`의 `$hostedTools`에 등록해 `build\ui-tools`로 보관·배포한다.
- [ ] 중복 전역 헤더와 중복 뒤로가기가 없다.
- [ ] 최초 설정 화면을 반복 노출하지 않는다.
- [ ] 키보드 포커스와 축소 모션 환경을 확인했다.
- [ ] 테스트·타입 검사·프로덕션 빌드를 통과했다.
- [ ] `tool-guideline-ack.json`에 도구 ID를 추가했다.
