# Prombot 프롬프트 도구 이식 기록

## 확인한 원본

- 웹 제품: https://prombot.net/
- 공개 코드: https://github.com/JioChoi/NAI-Prompt-Randomizer
- 검토 커밋: `9c15bd0f2e779908387b1adf427771bc837efd7b`
- 핵심 파일: `README.md`, `index.html`, `js/script.js`, `js/worker.js`, `index.js`

공개 코드는 시작 프롬프트, 포함·제외 조건, 무작위 본문, 끝 프롬프트를 합치고 중복과 특정 태그를 제거합니다. 옵션은 `localStorage` 또는 서버 프리셋에 저장하고, 생성 이미지는 페이지 DOM에만 추가하므로 새로고침 시 기록이 사라집니다.

현재 웹 제품은 공개 저장소보다 발전한 React 화면이며 프리셋에 프롬프트·캐릭터·필터·이미지 설정을 함께 저장합니다. 공개 저장소의 서버와 NovelAI 로그인·이미지 생성 경로는 게임기획 스튜디오에 포함하지 않았습니다.

## 스튜디오에 이식한 범위

- 시작 프롬프트 + 포함 조건 + 본문 + 끝 프롬프트 조합
- `~태그` 형식의 제외 조건
- `<A|B|C>` 형식의 로컬 동적 선택
- `{{변수명}}` 형식의 재사용 변수
- 네거티브 프롬프트가 본문의 동일 태그를 제거하는 처리
- 정규화한 태그 중복 제거
- 이름·설명·분류·대상 도구·선호 모델·temperature·태그를 포함한 프리셋
- 검색, 최근 사용/수정/이름 정렬, 사용 횟수
- 완성 프롬프트 클립보드 복사

외부 2GB급 태그 인덱스 검색, NovelAI 자격 증명, 이미지 생성 API, 커뮤니티 업로드, 자동 생성은 포함하지 않았습니다. 기본 도구를 API·로그인·외부 서버 없이 빠르게 실행하기 위한 경계입니다.

## 저장 수명

| 데이터 | 위치 | X 버튼 | 완전 종료 | 다음 실행 |
|---|---|---:|---:|---:|
| 저장 프롬프트와 조합 설정 | `%LOCALAPPDATA%\\GameDesignStudio\\prompt-library.json` | 유지 | 유지 | 복원 |
| 사용 횟수·최근 사용 시각 | 같은 JSON | 유지 | 유지 | 복원 |
| 완성 프롬프트 사용 기록 | C++ 프로세스 메모리 | 유지 | 소멸 | 복원 안 함 |

X 버튼은 창만 숨기고 C++ 프로세스를 트레이에 남기므로 기록이 유지됩니다. 트레이 메뉴 또는 설정의 완전 종료는 프로세스를 끝냅니다. 사용 기록은 처음부터 디스크에 기록하지 않으므로 삭제 파일이나 별도 정리 작업이 남지 않습니다.

## 코드 경계

- `native/PromptLibraryStore.cpp`: 원자적 프리셋 저장, 메모리 기록, 명령 처리
- `native/main.cpp`: `prompt:*` 명령 라우팅과 프로세스 수명
- `ui/src/promptLibrary.ts`: 변수·동적 선택·포함/제외·중복 제거 조합 엔진
- `ui/src/PromptLibraryTool.tsx`: 현재 스튜디오 톤앤매너의 편집·프리셋·기록 UI
- `scripts/qa-prompt-library.mjs`: 저장, 조합, 복사, 세션 기록, 화면 오버플로 자동검사
