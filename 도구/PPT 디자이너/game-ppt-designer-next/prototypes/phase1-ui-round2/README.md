# Phase 1 Program UI Round 2

정적 HTML/CSS로 만든 GAME PPT DESIGNER 프로그램 UI prototype 7종이다. React, Electron, Tauri, production renderer, PPTX export 구현은 포함하지 않는다.

모든 화면은 다음 실제 게임 기획 fixture를 사용한다.

> 회피 ×3 → 시간 파편 획득 → 시간 정지 5초 → BREAK → 받는 피해 +50%

Round 2에서 만든 A Editorial, B Mechanism, C Professional 실제 render를 slide fixture asset으로 재사용했다.
