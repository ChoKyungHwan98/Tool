# 패턴 디자이너 편집기 셸 명세

## 제품 문장

FSM·HFSM·행동 트리의 구조와 실행 흐름을 한 화면에서 설계하고 검증하는 로컬 전투 패턴 도구.

## 정보 구조

- 왼쪽 `패턴 목록`: 프로젝트 안의 FSM·HFSM·행동 트리와 현재 노드 구조를 탐색한다.
- 가운데 `그래프`: 편집 작업의 주인공이며 가능한 한 큰 면적을 사용한다.
- 오른쪽 `속성`: 선택한 노드가 있을 때만 보이고 닫을 수 있다.
- 아래 `보조 패널`: 검증·실행 기록·블랙보드를 필요할 때만 펼친다.
- 위 `실행 제어`: 편집 모드와 런타임 상태를 분리해 표시한다.

장면, 애셋 브라우저, 액션 타임라인처럼 아직 구현하지 않은 기능을 화면에 미리 배치하지 않는다.
도킹 패널과 메뉴의 수로 전문성을 흉내 내지 않고, 현재 작업에 필요한 정보만 유지한다.

## 시각 문법

- 통합 스튜디오와 같은 짙은 중립색 표면과 청록 강조색
- 상태 의미가 있을 때만 초록·노랑·빨강·보라를 제한적으로 사용
- 카드보다 행, 트리, 도구막대, 속성 섹션을 우선
- 본문 12–13px, 핵심 이름 13–14px의 조밀하지만 읽히는 위계
- 장식용 그라디언트, 가짜 상태바, 엔진 로고, 의미 없는 상시 패널 금지
- 선택·호버·실행·성공·실패 상태를 색과 선 굵기로 함께 구분

## 상호작용 규칙

- 패턴 종류는 왼쪽 목록에서 전환한다. 캔버스 안에 중복 탭을 두지 않는다.
- 노드를 선택하면 같은 대상을 캔버스·구조 트리·속성 패널이 함께 가리킨다.
- 속성 패널과 패턴 목록은 독립적으로 접을 수 있다.
- 보조 패널은 36px 레일을 유지하며 한 번에 한 내용만 연다.
- 실행 중인 노드는 캔버스와 속성 패널에서 동시에 표시한다.
- 외부 런타임은 내부 그래프 모델을 대체하지 않고 어댑터로만 연결한다.

## 수용 기준

- 1280×720에서 전체 페이지 가로·세로 스크롤이 생기지 않는다.
- FSM·HFSM은 XState, 행동 트리는 Mistreevous로 실제 한 단계 실행이 된다.
- 검증 결과와 실행 기록은 접힌 상태에서도 개수를 확인할 수 있다.
- 패널을 닫아 캔버스 면적을 확보할 수 있다.
- UI 문구는 한국어를 기본으로 하고 도메인 고유명·식별자는 원문을 유지한다.
