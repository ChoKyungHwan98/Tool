# UX Spec

워크벤치는 마케팅 페이지가 아니라 Excel, DataGrip, Unreal Editor처럼 반복 작업에 집중하는 데스크톱 도구여야 한다.

## Layout

- 상단에는 프로젝트 문맥, `전체 구조 | 테이블 편집 | 테이블 설계`, 공통 작업만 둔다.
- 왼쪽은 검색·선택·생성·삭제를 담당하는 접이식 테이블 탐색기다.
- 오른쪽은 대화 중심의 접이식 AI 패널이다. 공급자와 모델은 설정 안에서만 선택한다.
- 1280px 미만에서는 좌우 패널을 48px 레일로 유지하고, 한 번에 하나만 중앙 위에 오버레이로 연다.
- 하단 서랍은 필요한 순간에만 열리는 `문제 | 변경 검토` 작업 영역이다.
- Migration은 위험 변경을 위한 내부 계획이며 독립 화면이나 독립 탭이 아니다.
- History는 실행 취소·다시 실행 옆의 상단 팝오버에서 확인한다.
- CSV/JSON 출력과 데이터 계보는 검토 가능한 내보내기 서랍에서 확인한다.

## Interaction Rules

- 아이콘 버튼은 툴팁과 접근 가능한 이름을 제공한다.
- 스키마 변경은 typed Command를 통하고 위험 변경은 적용 전에 변경 검토를 거친다.
- 테이블·열 속성은 `테이블 설계`에서 편집하며 AI 패널이나 좁은 검사기에 두지 않는다.
- 테이블 편집은 A1 스키마 행과 A2 이후 데이터 행을 구분하고 Excel의 선택·이동·붙여넣기 관습을 따른다.
- AI 제안은 실제 Command와 시각적으로 분리하고 안정된 테이블·열·관계 ID에 연결한다.
- 런타임 출력 헤더에서 원본 열까지 데이터 계보를 추적할 수 있어야 한다.

## Schema Map Visual Language

- 프로젝트를 열면 전체 구조가 첫 화면으로 열린다.
- 테이블은 큰 장식 카드가 아니라 훑어보기 쉬운 밀도의 구조 카드로 표시한다.
- `PK`는 황색, `FK`는 청색, `REF`는 녹색, 오류는 빨강만 사용한다.
- 관계선은 테이블 중앙이 아니라 실제 원본 열과 대상 키 행에 연결한다.
- 전체 관계는 중립적으로, 선택 테이블과 직접 경로는 선명하게 표시한다.
- 화면 맞춤 상태에서도 테이블명과 PK/FK 요약은 11px 미만으로 내려가지 않는다.

## Accessibility

- 키보드 포커스는 항상 보여야 한다.
- 공식 최소 화면은 1024×720이며 좌우 패널, 메뉴, 서랍이 중앙 작업을 가리지 않아야 한다.
- 긴 이름은 겹치지 않고 말줄임표와 전체 이름 툴팁을 제공한다.

## Current Completion

- 가상화된 그리드는 셀·범위 편집, 행 작업, 다중 셀 붙여넣기, 시트 탭, 찾기·바꾸기, 다중 정렬·필터, 열 크기·순서 변경과 정확한 Undo·Redo를 지원한다.
- 잘못된 값은 셀 주변과 문제 목록에 함께 표시한다.
- 변경 검토는 영향, 검증 결과, 데이터 변환 계획, 적용·취소를 한 작업 흐름으로 보여준다.
- AI 패널은 로컬 Mock과 명시적으로 설정한 무료 OpenRouter 모델만 사용하며 행 데이터는 보내지 않는다.
- 가져오기는 파일·시트, 테이블·열, PK 후보, 승인할 FK 후보 순으로 확인한다.
- 내보내기는 출력·형식·파일명, 검증, 내용·계보를 확인한 뒤 실행한다.
